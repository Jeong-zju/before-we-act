# Data

The public All-5 dataset is hosted at
https://huggingface.co/datasets/B111ue/RoboFactory-5Task-RGBD-Decentralized.
It contains synchronized local wrist RGB-D demonstrations and per-robot proprioception for five
tasks with 2, 3, and 4 robots. Each task includes manifests and strict audits. Stored depth is
decoded from millimetres to native metric depth before DeFM encoding.
